Build the SKA is the current rehearsal default: AA1 snapshot → AA1 6 h → AA2 → AA* → AA4. The shorter Build + Earth rotation story remains available when isolating aperture synthesis is more useful.

Snapshot and 6 h remain freely selectable at every stage for facilitator improvisation. Forward/Back returns to the recommended story sequence.

Blue marks the independent baseline samples; orange shows their complex-conjugate counterparts. Animated tracks run chronologically from H = −3 h to +3 h. Both display modes use the same validated geometry. Dense stages use stage-dependent representative display subsets so the growing array visibly fills more of the uv plane; imaging still uses all baselines.

When Animated tracks is selected, “After observation” holds the new reconstruction until the six-hour track animation has finished. “Immediate” shows it as soon as the local calculation is ready.

Outreach view shows the dirty interferometric image. Science image uses a finer Fourier grid and an idealised constrained iterative reconstruction.

A captured camera image is retained in memory until “New image”. You can switch sources without losing it.
